# Recorded experiments

The timestamped subdirectories contain configurations, per-epoch training logs,
and final test summaries copied from the completed checkpoint archive.
Absolute scratch paths have been anonymized; numeric metrics are unchanged.
See [comparison.md](comparison.md) for the three selected runs.

`ce_official_identity_disjoint_summary.json` is an earlier CE evaluation retained
from repository history. It evaluates epoch 15 of a different run and is not
included in the selected three-run comparison. Do not mix it with the best-AUC
checkpoint results from the timestamped directories.

Checkpoints, images, and dataset manifests are not included here.
